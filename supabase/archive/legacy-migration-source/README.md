# Archived pre-reconciliation migration files

These files were present in the repository's migration directory before the 2026-11-06 reconciliation. Their filename versions did not consistently match the live Supabase migration ledger, and some filenames duplicated version numbers. They are retained here for audit/provenance only and are **not** Supabase CLI migrations.

The canonical `supabase/migrations/` directory has been reconstructed from the applied `supabase_migrations.schema_migrations` ledger for the Circle Panda Rebuilt project. Do not move these archived files back into `supabase/migrations/` or replay them.
